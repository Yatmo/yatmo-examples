# React listing page with @yatmo/react

A complete real estate listing page in React (Vite): facts, the Yatmo neighbourhood map, the nearest places and the
neighbourhood text, with the [@yatmo/react](https://www.npmjs.com/package/@yatmo/react) components.

```bash
npm install
echo "VITE_YATMO_KEY=your_frontend_key" > .env
npm run dev
```

Add the dev server's origin (localhost) to the allowed domains of your frontend key. For a Next.js page that
renders the text on the server (indexable), see the [@yatmo/react README](https://www.npmjs.com/package/@yatmo/react#server-rendering-for-search-engines).
